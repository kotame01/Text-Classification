# 🧠 Text Classification using TF-IDF and Support Vector Machine (SVM)

## 📌 Project Overview

This project focuses on building a Machine Learning based **Text Classification Pipeline** using Natural Language Processing (NLP) techniques. The model classifies textual data into multiple predefined categories by transforming raw text into numerical features and training a supervised learning algorithm.

The workflow includes data preprocessing, feature extraction using TF-IDF vectorization, model training using Support Vector Machine (SVM), and performance evaluation using standard classification metrics.

---

## 🚀 Objectives

- Perform text preprocessing and feature engineering
- Convert textual data into numerical representation using TF-IDF
- Train a classification model using Support Vector Machine (SVM)
- Evaluate model performance using Accuracy Score and Classification Report
- Build an end-to-end machine learning pipeline for multi-class text classification

---

## 📂 Dataset Used

This project uses the **20 Newsgroups Dataset**, a popular benchmark dataset for text classification tasks. It contains approximately 20,000 newsgroup documents partitioned across 20 different categories.

---

## 🛠️ Tech Stack

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Support Vector Machine (SVM)
- Jupyter Notebook / VS Code

---

## ⚙️ Project Workflow

1. Data Collection using Scikit-learn dataset loader
2. Data Splitting (Train-Test Split)
3. Text Feature Extraction using TF-IDF Vectorizer
4. Model Training using SVM Classifier
5. Model Evaluation using:
   - Accuracy Score
   - Precision
   - Recall
   - F1-Score
6. Performance Analysis

---

## 📊 Model Evaluation

The trained classification model is evaluated using standard classification metrics:

- Accuracy Score
- Confusion Matrix
- Classification Report (Precision, Recall, F1-Score)
